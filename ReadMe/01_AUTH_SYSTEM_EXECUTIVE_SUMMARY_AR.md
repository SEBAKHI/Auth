# AuthSystem — الملخص التنفيذي

## منصة هوية مؤسسية للمنظمات متعددة التطبيقات والمستأجرين

---

### ما هو AuthSystem؟

نظام AuthSystem هو منصة مركزية لإدارة الهوية تتعامل مع **المصادقة** (من هم المستخدمون)، و**التفويض** (ما يمكن للمستخدمين فعله)، و**سجل التدقيق** (ما فعله المستخدمون) — عبر جميع تطبيقاتك، من نظام واحد.

مبني على .NET 10.0 بمعايير أمان رائدة في الصناعة، يستبدل AuthSystem الحاجة لحلول هوية مجزأة بمنصة واحدة موحدة وجاهزة للمؤسسات.

---

### تكلفة عدم التحرك

| التأثير | المخاطرة |
|---------|----------|
| **4.88 مليون دولار** عالمياً (تقرير IBM لتكلفة اختراق البيانات، 2024) | **متوسط تكلفة اختراق البيانات** |
| حتى **4% من الإيرادات السنوية العالمية** | **غرامات عدم الامتثال لـ GDPR** |
| **67% من المستهلكين** يفقدون الثقة بالشركة بعد اختراق بياناتها | **ثقة العملاء بعد الاختراق** |
| **80% من الاختراقات** تتضمن بيانات اعتماد مسروقة (تقرير Verizon DBIR، 2024) | **الهجمات المرتبطة بالهوية** |
| **6 إلى 12 شهراً** من عمل فريق من 3 إلى 5 مهندسين لميزات مماثلة | **تكلفة البناء الداخلي** |

> كل يوم بدون نظام هوية متين هو يوم من المخاطر المتراكمة.

---

### ما الذي تحصل عليه

| القيمة التجارية | القدرة |
|----------------|--------|
| حماية ضد هجمات GPU الحديثة؛ أقوى خوارزمية متاحة | **أمان كلمات المرور بمعايير رائدة** (Argon2id — موصى به من OWASP) |
| تسجيل دخول واحد لجميع تطبيقات الشركة — يقلل الاحتكاك وتكاليف الدعم | **تسجيل دخول موحد عبر التطبيقات** |
| إدارة شركات/أقسام متعددة من منصة واحدة | **دعم المؤسسات متعددة المستأجرين** |
| معرفة من فعل ماذا ومتى — جاهز للامتثال مع GDPR و SOC 2 و HIPAA و PCI-DSS | **سجل تدقيق شامل** |
| تحكم دقيق بالوصول يتناسب مع تعقيد مؤسستك | **صلاحيات هرمية مع أحرف البدل** |
| دعم الفرق العالمية فوراً | **دعم 7 لغات (بما فيها RTL)** |
| الحماية مضمنة وليست ملحقة | **تحديد معدل الطلبات ورؤوس أمان مدمجة** |

---

### AuthSystem مقابل أنظمة الهوية التقليدية

| AuthSystem | الأنظمة التقليدية (مثل ASP.NET Identity) | الجانب |
|------------|------------------------------------------|--------|
| Argon2id (المعيار الذهبي الحالي) | bcrypt (آمنة لكن تم تجاوزها) | **تجزئة كلمات المرور** |
| هرمي مع أحرف البدل (`admin:*`) | أدوار/مطالبات مسطحة | **الصلاحيات** |
| تسجيل دخول موحد مدمج عبر جميع التطبيقات | إعداد منفصل لكل تطبيق | **دعم التطبيقات المتعددة** |
| تسجيل تلقائي وشامل | يتطلب تطويراً مخصصاً | **سجل التدقيق** |
| دعم أصلي للمؤسسات | غير مشمول | **تعدد المستأجرين** |

> **ملاحظة**: نظام ASP.NET Identity مكتبة متينة للسيناريوهات البسيطة. AuthSystem مصمم خصيصاً للمؤسسات التي تحتاج إدارة هوية متعددة التطبيقات والمستأجرين بأمان وامتثال على مستوى المؤسسات.

---

### الأساس التقني

| التقنية | المكون |
|---------|--------|
| NET 10.0. | الخلفية |
| SQL Server + Dapper (مكتبة Micro-ORM عالية الأداء) | قاعدة البيانات |
| Blazor (نمط Server + WebAssembly) | لوحة الإدارة |
| YARP (وكيل Microsoft العكسي) | بوابة API |
| Argon2id و JWT RS256 ورؤوس متوافقة مع OWASP | الأمان |
| Serilog (منظم وقابل للاستعلام) | التسجيل |

---

### تغطية الامتثال

سجل التدقيق وضوابط الوصول في AuthSystem تساعد في تلبية متطلبات:

**GDPR** | **SOC 2** | **HIPAA** | **PCI-DSS** | **التدقيق الداخلي**

كل إجراء يُسجل مع هوية المستخدم والطابع الزمني وعنوان IP وسجل التغييرات الكامل.

### التقييم الأمني السريع

قيّم نظام الهوية الحالي لديك. كل إجابة بـ "لا" تمثل خطراً محتملاً:

</div>

- [ ] هل يستخدم نظامك خوارزمية تجزئة كلمات مرور تعتمد على الذاكرة (Argon2id)؟
- [ ] هل لديك قفل تلقائي للحساب بعد محاولات تسجيل دخول فاشلة؟
- [ ] هل يمكنك تدقيق من وصل إلى أي بيانات ومتى؟
- [ ] هل تدعم تسجيل دخول موحد عبر تطبيقات متعددة؟
- [ ] هل نقاط نهاية API محمية بتحديد معدل الطلبات؟
- [ ] هل تطبق رؤوس أمان موصى بها من OWASP؟
- [ ] هل يمكنك إدارة الصلاحيات بشكل هرمي (ليس فقط أدوار مسطحة)؟
- [ ] هل تدعم انتهاء صلاحية الأذونات بناءً على الوقت؟
- [ ] هل نظامك جاهز للامتثال مع GDPR/SOC 2/HIPAA؟
- [ ] هل يمكنك إدارة مؤسسات متعددة من منصة واحدة؟

<div dir="rtl" lang="ar">

**إذا أجبت بـ "لا" على 3 أسئلة أو أكثر**، فقد تكون مؤسستك معرضة لمخاطر مرتبطة بالهوية يعالجها AuthSystem فوراً.
